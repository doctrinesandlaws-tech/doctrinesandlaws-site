# Doctrines & Laws: "Law, explained."

Source for https://doctrinesandlaws.netlify.app, a free legal-literacy hub run by Doctrines & Laws Chambers, New Delhi.

- `index.html`: the whole site. Content lives in the JavaScript arrays at the top of the `<script>` (POSTS, DEVS, RIGHTS, CASES, MAP, MAXIMS, RES).
- Every push to `main` deploys automatically on Netlify.
- Managed by the Doctrines & Laws website agent. See `AGENTS.md`.
